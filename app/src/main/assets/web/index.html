        Backfill from Google Takeout

        At takeout.google.com select YouTube and YouTube Music → history, set the history format to JSON, then import watch-history.json here. Only YouTube Music entries are imported. Takeout doesn't record how long you listened, so each entry is counted as a 3-minute play (marked "estimated" in History).
